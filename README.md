# Chisom Ojeh — Portfolio

Personal portfolio site with a black-and-cosmic theme: interactive orbit console,
live project previews, filterable works archive, and downloadable CV.

## Files

- `index.html` — homepage (hero, featured projects, about, journey, contact)
- `works.html` — full project archive with stack filter
- `styles.css` — theme + layout
- `script.js` — starfield, constellation, filters, theme toggle
- `Chisom-Ojeh-CV.pdf` — downloadable CV

## Run locally

Just open `index.html`, or serve the folder:

```bash
npx serve .
```

## Deploy

Static site, no build step. On Vercel: **Add New → Project → Import** this repo,
framework preset **Other**, deploy.
